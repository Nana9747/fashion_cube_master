# Fashion Cube — E-Commerce Web Application

A responsive, full-featured e-commerce platform built with React, Redux, and Bootstrap.

---

## 🚀 Features

- **Product Catalog:** Browse products across multiple categories with dynamic filtering.
- **Product Details:** Dedicated view for single items with pricing, description, and specifications.
- **Shopping Cart:** Real-time cart state management using Redux.
- **Responsive Layout:** Mobile-friendly UI styled using Sass and React-Bootstrap.

---

## 🛠️ Tech Stack

- **Frontend:** React.js, React Bootstrap, Sass, Axios
- **Backend / Database:** Node.js, Express, MongoDB
